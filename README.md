## **Modules**
### **Combat Modules**
- **Focus Interrupt**: support Focus Interrupt task in various ways, and helps users to identify whether the cast of focus is interruptible/interrupt ready/ interrupt in cooldown
    - Standalone version: [https://www.curseforge.com/wow/addons/midnightfocusinterrupt](https://www.curseforge.com/wow/addons/midnightfocusinterrupt)
- **Combat Indicator**: display a text reminder when enter/leave combat and automatically disappear after a specified fade time with optional sound alert
- **Combat Timer**: display a MM:SS combat timer which records the combat duration with many customize options with it
- **BattleRes**: indicator: display the BattleRes states
- **Bloodlust Helper**: demonstrate bloodlust aura and register bloodlust activate and ready sound
- **Aura Helper**: create cutomizable aura containers to track buffs/debuffs on player/co-tank
### **Utility Modules**
- **Auction Helper**: a consumerables, enhancements, and craft quick search panel for the auction house
- **Gossip Helper**: automatically select the registered gossip options
- **M+ Panel Enhance**: display score and dungeon name and clickable M+ dungeon portal on the M+ Panel
- **Auto Roll**: automatically select Need/Greed/Pass on the loot roll window based on customizable rules
- **Talent Reminders**: display talent reminders when you enter a Mythic Dungeon
### **Skin Modules**
- **Micro Menu**: custom quick-access menu for character, bags, talents, social, and more, replacing Blizzard's default micro menu
- **Countdown**: customizable replacement for Blizzard's countdown timer, with customizable sound alerts
- **Text Warning**: customizable replacement for Blizzard's boss text warnings
### **Specialization Modules**
- **Warlock Reminders**: reminder for pet and healthstones for warlocks.
- **Demonology Portals**: display the count of portals summoned during this/last Tyrant for Demonology Warlocks

# 魔兽世界的工具合集插件 by HBLyx

## 若需要自定义,请使用: /hbt
- 在测试模式下，您可以拖动调整所有显示元素的位位置(建议：调整完成后，请关闭测试模式并重新加载) 

## **模组**
### **战斗模块**
- **焦点打断**: 以多种方式支持焦点打断，并帮助用户识别当前焦点施放的技能是否可打断/已准备好打断/处于打断冷却状态
    - 单独版本: [https://www.curseforge.com/wow/addons/midnightfocusinterrupt](https://www.curseforge.com/wow/addons/midnightfocusinterrupt)
- **战斗指示器**: 当进入/脱离战斗时显示一个文本提示并且播放一个可选的语音警报
- **战斗计时器**: 显示并记录战斗时间(MM:SS)以及多个自定义选项
- **战复计时器**: 显示战复的冷却和充能状态
- **嗜血助手**: 显示嗜血光环容器, 并在获得嗜血/英勇和疲劳类减益时播放可自定义的声音提醒
- **自定义光环追踪**: 追踪玩家/副坦克触发的光环，并显示和播放声音警报，支持自定义选项
### **实用模块**
- **拍卖助手**: 一个用于拍卖行的消耗品、附魔和制作材料快速搜索面板
- **对话助手**: 自动选择已注册的对话选项
- **大秘境面板增强**: 在M+面板上显示分数、地下城名称以及可点击的M+地下城传送门
- **自动Roll点**: 根据自定义规则自动在Roll点窗口上选择需求/贪婪/放弃
- **天赋提醒**: 当你进入一个史诗地下城时显示天赋提醒
### **美化模块**
- **微型菜单**: 自定义快捷菜单，快速访问角色、背包、天赋、社交等界面，替代暴雪默认的微型菜单
- **倒计时**: 可自定义的暴雪倒计时替代方案，带有可自定义的音效提醒
- **文本警告美化**: 可自定义的暴雪首领文本警告替代方案
### **职业模块**
- **术士提醒**: 为术士提供宠物和治疗石提醒
- **恶魔术传送门**: 显示恶魔术士本次/上次暴君期间召唤的传送门数量
